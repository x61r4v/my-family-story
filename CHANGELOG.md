# Changelog

All notable changes to **My Family Story** (the app itself, not the family data - the data has its own version counter, the Save chip's v-number).

## v1.1.0 · 2026-07-17

- Editing is now ON by default for everyone - `?edit=0` locks a session into viewer mode (was: hidden until `?edit=1`).
- The export now ships `uploads/default.jpg` (the default avatar) - it was missing from the zip.
- Removed the design-time Tweaks panel from the shipped app (node style, canvas texture and heritage accent are baked in as defaults).

## v1.0.0 · 2026-07-17

First public release.

- The time-scrubbing family tree: drag the year, watch the family grow; every stop is a time capsule.
- Focus view per person: life projector, story log, personal timeline, "Add a moment" (dated or undated).
- Full bilingual record - English / Hebrew - across tree, cards and stories.
- Edit tree mode: add people, partners, side-links; drag to rearrange; toolbar with Add / Find / Zoom / Done.
- Records Room: the desk (coverage score, do-next), People, World events, Places, Photos editors.
- The publish flow: local working copy + "Copy changes (for Claude)" baking.
- README in both languages + in-app guide (logo click / ☰ menu), CC BY-NC 4.0 license.
