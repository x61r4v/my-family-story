# הסיפור המשפחתי שלי 🌳

*תיעוד חי של המשפחה - שנבנה כדי לחקור אותו יחד, שנה אחר שנה.*

**גרסת אפליקציה: v1.1.1** · [יומן שינויים](CHANGELOG.md)

![עץ המשפחה בשנת 1997](readme-assets/hero.webp)

**הסיפור המשפחתי שלי** הוא עץ משפחה אינטראקטיבי שמתייחס למשפחה לא כתרשים - אלא כסיפור. גוררים את ציר הזמן וצופים במשפחה גדלה, דור אחר דור. פותחים כל אדם וצועדים דרך חייו - צעדים ראשונים, חתונות, עליות, ארוחות שישי שקטות - בתמונות וברגעים כתובים קטנים, בעברית ובאנגלית.

הוא נבנה לשני סוגי ערבים:

- **ערב משפחתי**: הורים וסבים יושבים עם הילדים, מדפדפים בין השנים וצוללים לסיפורים שמאחורי התמונות. ("רגע, לסבא היה *אופנוע*?")
- **עבודת שורשים**: מקום שבו ילד אוסף את הסיפורים שהוא שומע מהקרובים, ובסוף נשאר למשפחה משהו ששומרים.

הכול מגיע עם **משפחת דמו בדיונית (משפחת אדלר, 1903–היום)**, כדי שתרגישו איך זה עובד לפני שאתם יוצקים פנימה את המשפחה שלכם.

והוא **נולד לחיות בסביבות AI** - [Claude design, Claude Code, או כל כלי](#עבודה-על-הפרויקט-עם-claude) שיודע לקרוא תיקייה. עובדים עליו גם דרך הצ'אט *וגם* דרך קצת [וודו של ממשק](#שמירה--תהליך-הפרסום) (עריכות באפליקציה הופכות לקובץ שינויים שה־AI "אופה" לתוך הקבצים).

## סיור באפליקציה

### העץ וציר הזמן

המסך הראשי הוא עץ המשפחה - אבל הוא חי *בתוך הזמן*. הסרגל בתחתית נמתח מהלידה הראשונה שתועדה ועד היום:

- **גוררים את השנה**: ואנשים מופיעים כשהם נולדים, מתבגרים דרך תמונות מתקופתם, מתחתנים ונפרדים.
- **כל עצירה היא קפסולת זמן**: המשפחה בדיוק כפי שעמדה *באותה* שנה: מי ישב אז ליד השולחן, בני כמה כולם היו, זה לצד זה, כשאירועי העולם של אותו רגע ברקע.
- **לוחצים Play** ונותנים למאה שלמה להתגלגל לבד.
- **לחיצה על אדם** פותחת כרטיס תקציר: קשרי משפחה, האירוע האחרון בחייו וביוגרפיה. קו החיים שלו - מילדות לבגרות - מופיע מעל ציר הזמן המשפחתי, והסיפור מסופר מחדש מנקודת המבט שלו.

![לוח הסיפור של אדם - העולם שלו בכרטיס אחד](readme-assets/story-panel.webp)

- **אירועי עולם** (מלחמות, הנחיתה על הירח, שידור הטלוויזיה הראשון…) מנצנצים לאורך הציר - לחיצה מראה איך הם נגעו במשפחה.

![אירועי עולם - ההיסטוריה נוגעת במשפחה](readme-assets/world-events.webp)


בהגדרות (⚙) מחליפים **עברית / English**, מדליקים קשרים צדדיים (סנדק, "השכן שגידל אותו"), בוחרים איך מוצג שם המשפחה (בלידה / נוכחי / כפי שהיה באותה שנה) ועוד.

### מבט־עומק — חיים של אדם אחד

לחיצה כפולה על אדם (או "View life timeline" בכרטיס שלו) נכנסת אל חייו:

![מבט עומק - חיים המסופרים בתמונות וברגעים](readme-assets/focus-view.webp)

- **מקרן חיים** של התמונות שלו - גלילה או לחיצה בין השנים.
- **יומן סיפור החיים**: כל אירוע, מהלידה ועד היום, עם הסיפורים הקטנים שמאחוריו.
- **ציר זמן אישי** בתחתית, צבוע לפי פרקי חיים - ילדות, נעורים, שנים מאוחרות.

## פתיחה ומצב עריכה

האפליקציה היא עמוד HTML אחד - **‏`Family Tree.html`** - עם הסקריפטים והתמונות שלו. בלי התקנה, בלי חשבון.

פשוט פותחים את העמוד - כלי העריכה כבר שם, בסרגל העליון: **Edit tree** (העץ נעשה ניתן לעריכה), **תפריט ☰** (חדר הרשומות), ושבב ה**שמירה** שסופר שינויים שטרם נשמרו עבור [תהליך הפרסום](#שמירה--תהליך-הפרסום).

עריכה **דלוקה לכולם כברירת מחדל** - זו כל הנקודה: כל אחד במשפחה יכול להוסיף ולתקן (שום דבר לא משותף עד ששומרים ואופים). כדי לנעול מכשיר למצב צפייה בלבד - עמדה באירוע משפחתי, קישור לקרובים רחוקים - פותחים פעם אחת עם `‎?edit=0` (חוזרים עם `‎?edit=1`).

אם מריצים את התיקייה מקומית, מגישים אותה משרת מקומי (דפדפנים חוסמים חלק מהיכולות ב־`file://`):

```
cd family-tree
python3 -m http.server     # ואז http://localhost:8000/Family%20Tree.html?edit=1
```

## הוספת אנשים, תמונות ורגעים

### אנשים — מצב Edit tree

לוחצים **Edit tree**. ציר הזמן מחליק הצידה, הכרטיסים מתכווצים כך שכל העץ נכנס למסך, וסרגל כלים עולה:

![מצב עריכה - כל העץ, עם סרגל ההוספה](readme-assets/edit-mode.webp)

- **Add** ← אדם חדש, בן/בת זוג, או קשר צדדי (קשר לא־דמי: סנדק, השכנה שגידלה).
- לוחצים על כרטיס וממלאים שמות (עברית + אנגלית), לידה/פטירה, מקומות וביוגרפיה.
- **Find a person** לקפיצה מהירה בעץ גדול.
- **Done** בסיום - שום דבר לא משותף עד שלא שומרים (בהמשך).

הכול נבנה להיות **קל, מהיר וכיפי** - משהו שעושים עם הילדים, או שהם עושים לבד. הכלל הוא *קודם עושים, אחר כך מעמיקים*: מוסיפים אדם עם שם בלבד, ומשלימים שנים, מקומות וסיפורים ככל שהמשפחה נזכרת. בלי טפסים מייסרים.

### תמונות

תמונות נזרקות ישר על האפליקציה - בלי מסכי העלאה:

- **גוררים תמונה** על כל משבצת תמונה (במבט העומק, או דרך תפריט ⋯ על תמונה).
- **חיתוך אווטאר**: לכל דיוקן בעץ יש עורך חיתוך במסך מלא, לכל תקופת חיים (צעיר / בוגר / מבוגר).
- עד הפרסום התמונות שמורות בעותק העבודה המקומי; הפרסום הופך אותן לקבצים אמיתיים ב־`photos/`.

### רגעים — הלב של העניין

במבט העומק, מרחפים בין שתי רשומות בסיפור החיים ומופיע קו דק - **"הוספת רגע"**. לכאן נכנסים הסיפורים שאוספים מהמשפחה:

- לרגע יש כותרת, סיפור, ואם רוצים גם תמונה - בשתי השפות.
- **רגע יכול להיות בלי תאריך.** ילדים כמעט אף פעם לא יודעים באיזו שנה קרה הסיפור של סבתא - אז מניחים אותו *בין* האירועים שאליהם הוא שייך ("איפשהו בין החתונה למעבר לחיפה"), והאפליקציה מציגה "בין 1934 ל־1943". את השנה אפשר להשלים אחר כך.

## עבודה על הפרויקט עם Claude

האפליקציה חיה בתוך פרויקט Claude - מה שאומר שהצ'אט לידה הוא לא תמיכה טכנית, אלא **עוזר מחקר, ארכיונאי ומעצב** שקורא וכותב כל קובץ. העורכים שבאפליקציה מצוינים לשדה אחד בכל פעם; Claude נועד לכל מה שגדול מזה. כמה דברים שאנשים באמת עושים:

**זורקים חומר גלם - ונותנים ל־ Claude לסדר.**

- מדביקים רשימה מבולגנת - *"הנה השמות והגילאים המשוערים מהצד של אמא, סדר אותם בעץ."* Claude מוסיף את האנשים, מחבר את הקשרים ומשלים שנים חסרות בהערכה.
- גוררים פנימה צרור סריקות - *"אלה כולן מהקופסה של רבקה; שבץ כל אחת אצל האדם הנכון ובתקופה הנכונה."*
- מדביקים תמלול של ראיון מוקלט - *"פרק את הסיפורים של סבא לרגעים מתוארכים על ציר החיים שלו, בקול שלו."*
- מעבירים שרשור וואטסאפ שבו הדודות התווכחו מי נולד איפה - Claude מחלץ את העובדות ומסמן את המחלוקות.

**יוצרים דברים חדשים מהרשומה.**

- *"צור מצגת של מאה שנות אדלר למפגש המשפחתי" - Claude קורא את `family-data.js` ובונה מצגת כקובץ חדש בפרויקט.*
- **ספר משפחה** להדפסה או פוסטר של העץ למסגרת.
- קובץ **ערב טריוויה** - עשרים שאלות מתוך הסיפורים ("מי טיפס על האקליפטוס ב־1949?").
- דף יום־הולדת לאדם אחד, תפור מהתמונות והרגעים שלו.

**מחקר ותחזוקה.**

- *"אילו אירועי עולם כדאי להוסיף בין 1948 ל־1956, בהינתן שהמשפחה הייתה בחיפה?"*
- *"למי עדיין אין סיפורים? נסח לי שאלות ראיון לארוחת שישי."*
- *"תרגם כל סיפור שחסרה לו הגרסה העברית, ושמור על הטון."*
- *"תן לי הורדה של כל הפרויקט" - גיבוי zip, בכל רגע.*

**משנים את האפליקציה עצמה.** הכול HTML/JS קריא - אפשר לבקש פיצ'ר חדש ("הוסף כרטיס ימי־הולדת החודש"), צבע אחר לקרובים החיים, או מסך חדש לגמרי. `CLAUDE.md` מלמד את Claude את מבנה הנתונים, אז שינויים נוחתים נקי.

> ההרגל שגורם לזה לעבוד: **לא מנקים את המידע לפני שמביאים אותו**. מביאים את הבלאגן - רשימות, צילומי מסך, תאריכים חצי־זכורים - ונותנים ל־ Claude לתייק. אחר כך בודקים מה הוא עשה בחדר הרשומות.

## שמירה — תהליך הפרסום

זה החלק החריג - והקסום - כאן. אין שרת. **Claude הוא השרת.**

התהליך הזה מיועד לשינויים שעושים **בממשק של האפליקציה** - תמונות שנגררו, חיתוכים, עריכות, אנשים חדשים, רגעים. שינויים שמבקשים **בצ'אט של Claude** לא צריכים אותו: Claude כותב אותם ישירות לקבצים, והם נשמרים ברגע שהוא מסיים.

כל פעולה (תמונות, חיתוכים, עריכות, אנשים חדשים, רגעים) נשמרת מיידית לעותק עבודה מקומי - רענון לא מאבד כלום. שבב ה**שמירה** בסרגל העליון סופר:

![חלון השמירה](readme-assets/save-dialog.webp)

כשמוכנים להפוך את השינויים לקבועים ומשותפים:

1. לוחצים על שבב השמירה ← **"Save to the shared family record"**.
2. עוברים על רשימת השינויים (אפשר לבטל, לשחזר או למחוק שינויים בודדים).
3. **Copy changes (for Claude)** - קובץ שינויים קטן (JSON) מועתק ללוח.
4. **מדביקים בצ'אט של Claude.** Claude "אופה" אותו: תמונות הופכות לקבצים אמיתיים, עריכות נכתבות לקובצי הנתונים, ומונה הגרסה עולה (v33 ← v34).

השבב יציג **"v34 · in sync"** - אצל כולם. ‏⌘Z / ⇧⌘Z מבטלים ומשחזרים כל שינוי מקומי לפני האפייה.

למה ככה? כדי שהכול יישאר תיקיית קבצים פשוטה - בלי חשבונות, בלי מסד נתונים, בלי שירות שנעלם בעוד חמש שנים. הרשומה המשפחתית שלכם היא שלכם, לתמיד, בקבצים שאפשר לקרוא.

## ייבוא לסביבת Claude משלכם

רוצים כזה למשפחה שלכם? זו תיקייה - קחו אותה:

1. **מורידים** את הפרויקט כ־zip (מבקשים מ־Claude: *"תן לי הורדה של כל הפרויקט"*).
2. בסביבת ה־Claude שלכם, **יוצרים פרויקט חדש**.
3. **גוררים את ה־zip (או את הקבצים) לצ'אט** וכותבים:
   > *פרוס את הקבצים האלה לשורש הפרויקט בדיוק כמו שהם - בלי לשנות כלום. אחר כך קרא את CLAUDE.md - זה מדריך ההפעלה שלך לאפליקציה.*
4. פותחים את `Family Tree.html` - משפחת הדמו מופיעה ועובדת בדיוק כמו כאן.
5. עכשיו הופכים אותו לשלכם. בקשות ראשונות טובות:
   - *"החלף את משפחת הדמו אדלר במשפחה שלי - הנה מה שאני יודע…"* (או בונים אדם־אדם במצב Edit tree)
   - *"נקה את כל תמונות וסיפורי הדמו אבל השאר את האפליקציה."*
   - *"הוסף אירועי עולם שחשובים למשפחה שלי: השנה שהמפעל נסגר, העלייה הגדולה ממרוקו…"*

**‏`CLAUDE.md` הוא השתלת הנשמה** - הוא מלמד כל Claude איך לאפות קובצי שינויים, להוסיף אנשים ולהרחיב את האפליקציה. אל תשאירו אותו מאחור.

## מתחילים מאפס - ניקוי הדמו

משפחת אדלר היא פיגומים - כך מפרקים אותם ומכניסים את המשפחה שלכם:

1. פותחים את **The desk** (תפריט ☰ ← The desk) ולוחצים על **"Copy the ask for Claude"** בתחתית - או פשוט אומרים ל־Claude:
   > *נקה את משפחת הדמו אדלר - כל האנשים, התמונות, הסיפורים ועריכות אירועי העולם - אבל השאר את האפליקציה עובדת. אחר כך עזור לי להתחיל רשומה משפחתית משלי.*
2. Claude מרוקן את `family-data.js`, מנקה את `photos/` ואת עריכות הדמו, ומאפס את מונה הגרסאות. האפליקציה נשארת שלמה - עץ ריק, מוכן.
3. מתחילים לשתול, איך שנוח:
   - **באפליקציה**: Edit tree ← מוסיפים את האדם הראשון (בדרך כלל האב הקדמון הוותיק ביותר שמכירים), ואז בני זוג וילדים.
   - **בצ'אט**: *"הוסף את סבא וסבתא שלי: יוסף נולד 1931 בבגדאד, נעימה נולדה 1934..."* - שופכים מה שיודעים, Claude בונה את העץ.
4. משאירים את אירועי העולם שמתאימים לגאוגרפיה של המשפחה, או מבקשים חדשים.

טיפ: מתחילים עם **שמות ושנים משוערות בלבד** - ערב אחד מקים את כל השלד. תמונות וסיפורים מגיעים אחר כך, ביקור אחרי ביקור.

## עבודה עם Claude Code וכלי AI אחרים

כל האפליקציה היא HTML + JS פשוטים - קריאים לכל כלי.

**Claude Code / טרמינל:**

```
cd family-tree
claude        # Claude Code קורא את CLAUDE.md אוטומטית
```

ואז עובדים רגיל: *"הוסף את סבתא רבקה, נולדה ב־1921 בווילנה"*, או מדביקים קובץ שינויים שהועתק מחלון השמירה ואומרים *"תאפה את זה"*. לצפייה מגישים את התיקייה משרת מקומי (ראו למעלה).

**Cursor / עורכי AI אחרים:** מכוונים אותם לתיקייה ומבקשים לקרוא קודם את `CLAUDE.md` - הוא מתעד את מודל הנתונים (`family-data.js`), את מערכת התמונות ואת נוהל האפייה המדויק.

**בלי AI בכלל?** אפשר לערוך ידנית את `family-data.js` (אנשים, זוגיות, אבני־דרך - JavaScript ידידותי ומוער) ולהניח קובצי תמונה ב־`photos/`. רק האפייה האוטומטית של עריכות מתוך האפליקציה תחסר.

## הסיפור מאחורי הפרויקט

הפרויקט תוכנן ונבנה מקצה לקצה **בשיחה עם Claude** - כל מסך, העץ הנע בזמן, מערכת הרגעים־ללא־תאריך ותהליך הפרסום של "הצ'אט הוא השרת" נולדו מאיטרציות בכלי העיצוב.

משפחת אדלר שבדמו היא **בדיונית לחלוטין** - חמישה דורות שנכתבו כדי להראות איך מרגישה רשומה מטופחת: תמונות בכל תקופה, סיפורים עם מרקם אמיתי, ואירועי עולם שזורים לאורך מאה שנה.

התקווה פשוטה: שאיפשהו, ילד יראיין את סבא שלו לעבודת שורשים, יקליד את הסיפורים כאן, יגרור פנימה את התמונות הישנות - ולמשפחה תישאר ירושה במקום שיעורי בית.
