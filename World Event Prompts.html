World events — photo prompts

One image per event on the timeline horizon — for each event, THE iconic picture — instantly recognizable at a glance, and gentle enough to show children. Each prompt is dated, so film stock, clothing and setting follow from the year. Paste into ChatGPT (or Gemini) as-is.

How to use

  1. Copy a prompt and paste it into ChatGPT or Gemini. No reference images needed — no recurring faces here, so any order works.
  2. Keep the heart of the scene centered. In the side panel the photo is cropped to a wide strip, so the prompts already ask for the subject in the central band — don't crop the result yourself.
  3. Drop the image straight into the app: open the event from the timeline horizon (or the world-events room) and drop the file onto its photo slot. The File name button copies a tidy name for your downloads folder.
  4. Tick the checkbox when an event has its photo — progress is remembered.
