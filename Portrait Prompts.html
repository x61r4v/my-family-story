Adler family — portrait prompts

One prompt per photo the tree can hold. Every prompt is dated to the year the photo would actually have been taken, and its film stock, lighting, clothing and setting follow from that year. Paste into ChatGPT (or Gemini) as-is.

How to get a consistent face across eras

  1. Generate the anchor shot first — the row tagged ★ Anchor on each card below: the person’s Adult portrait (or their only portrait). All prompts are standalone, so any order works, but the anchor gives you a face to hold onto.
  2. Then age or de-age from it. In the same ChatGPT conversation, attach the anchor image and use the follow-up template below. Gemini: same trick — attach the image as a reference.
  3. For blood relatives, attach the parent's portrait alongside the prompt and add: "This is their son/daughter — carry a clear family resemblance." The written prompts already spell out the inherited features, so this is a bonus, not a requirement.
  4. Tree avatar = the person's most recent portrait, cropped to a square head-and-shoulders. Each card below marks which shot to crop.
